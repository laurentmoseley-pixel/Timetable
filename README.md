# Timetable Builder

A school timetable builder, cover planner and staff and pupil Viewer, in single HTML files that run in
the browser. No install, no accounts, no tracking: the data stays where the school chooses.

## The website

This repository is also the project's website (GitHub Pages):

| Page | What it is |
|---|---|
| `index.html` | The home page |
| `builder.html` | The Timetable Builder (version 3.3). It opens with a made-up demo school. |
| `viewer-demo.html` | The staff Viewer, with the demo school |
| `pupil-demo.html` | The pupil Viewer, with a demo pupil |
| `guides/` | The guides, as web pages |
| `downloads/` | The Power Apps edition |

To turn the website on: **Settings**, **Pages**, then under **Build and deployment** choose **Deploy
from a branch**, branch **main**, folder **/ (root)**, and **Save**.

## Using the Builder

Open `builder.html` in Edge, Chrome or Safari, online or after downloading it. Everything it needs is
inside the file.

## No school data here

The demos use a made-up school. Never commit a school's own timetable, backups or published Viewer
files to this repository.
